# Sophie Pallas

Sophie Nectar is a text-first Strudel music workstation for making Vocaloid-ish
electronic music from sections, samples, and scripts.

## Download

[Download Sophie Pallas for Linux](https://github.com/tiagohierath/sophiepallas/releases/latest/download/sophie-nectar-0.1.0-linux-x86_64.tar.gz)

Extract the archive and run `./bin/sophie-nectar`. For a desktop-menu install,
run `./install.sh`. Linux users need `ffmpeg` and `mpv` for rendering and
playback.
