sophie nectar

An early-90s rig rebuilt from open-source browser parts. Strudel is the Atari sequencer, dough and web-synth are the hands-on synths, mono82 is the step box. The work stays in text files.

strasbeat

Sequencer, editor and arrangement. Patterns are .js files on disk, piano roll, MIDI capture to file, WAV export.
= the Atari + Cubase brain, and the floppy of sequence files
AGPL-3.0 · strudel-based · sections as files
open source

dough keyboard

Play a sound by ear, tweak it live, and it prints the strudel line to paste into a section.
= the mono/FM synth you dial in by hand
AGPL-3.0 · vendored, runs local · continuous morph (not note-triggered)
open bakery

web-synth

8-operator FM synth, effects, MIDI editor and loopers, Rust compiled to WASM on the audio thread.
= the DX-style FM voice, metallic bass and bells dough doesn't make
MIT · self-hostable · live build at notes.ameo.design
open source

mono82

32-step, 4-track sequencer. Per step: note, volume, decay, FM, tone, pan, probability. Sine + noise voices.
= a lean step sequencer, the 16-step UI with A/B parts
no license (local use only) · vendored, runs local · static, offline
open source

how they fit

1. Design a sound in dough, copy the strudel line.

2. Build the pattern in strasbeat, paste the sound in, save the section as a file.

3. Add drums and steps from mono82.

4. Export to WAV, then the tape pass in ffmpeg (wow/flutter, saturation, hiss) is what makes it 1991.

a hub, not a rebuild · each tool is existing open source, opened in its own tab
